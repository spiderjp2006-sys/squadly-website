# ⚡ Squadly (سوادلي) - منصة الموديريتورز والمستقلين المعتمدين

**سوادلي (Squadly)** هي منصة وساطة رقمية آمنة تهدف للربط بين أصحاب الأعمال والموديريتورز (مديري الصفحات والدعم الفني) والمستقلين المعتمدين، مع تطبيق نظام ضمان مالي صارم لحماية الطرفين من النصب.

---

## 🛡️ مميزات المنصة الرئيسية

* **نظام الضمان المالي (Escrow System):** يتم حجز قيمة الشغلة أو الشفت في المنصة، وتوزيع المستحقات فور إتمام العمل (**75% للمستقل / 25% عمولة المنصة**).
* **توثيق الحسابات الصارم (Verified Mods):** لا يمكن للموديريتور استقبال شفتات أو التواصل مع العملاء إلا بعد رفع الهوية الوطنية (KYC) وسابقة الأعمال ومراجعتها من قبل الإدارة.
* **واجهة داكنة مريحة (Dark Mode UI):** تصميم مودرن بألوان نيون بنفسجية وتأثيرات إضاءة لتجربة استخدام احترافية.
* **لوحة تحكم أدمن خفية (Admin Dashboard):** إمكانية الوصول للوحة التحكم من خلال آلية سريّة مدمجة بالصفحة الرئيسية للمراجعة والقبول الفوري للطلبات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** HTML5, CSS3 (Modern Variables & Glow Effects), JavaScript (ES6+ Module).
* **Backend & Database:** Firebase Suite
  * **Firebase Authentication:** لإدارة تسجيل دخول وإنشاء حسابات المستخدمين والأدمن.
  * **Cloud Firestore:** قاعدة بيانات لحظية لتخزين المعاملات الماليّة وطلبات التوثيق وبيانات المستخدمين.
  * **Firebase Storage:** لتخزين صور الهويات الوطنية وملفات التوثيق بأمان.
